# 抖音创作者后台深层数据复盘

只看播放量和点赞率复盘不出爆款规律。这套工具让 AI 通过你已登录的浏览器接管创作者后台，自动拉取 **2 秒跳出率、5 秒完播率、平均播放时长、点赞/评论/收藏/转发拆解率** 等深层指标，一键出单文件 HTML 复盘报告。

## 怎么用

1. 先双击打开 [`1-先看这个-说明书.html`](./1-先看这个-说明书.html) 了解指标口径和报告样式。
2. 把 [`2-发给你的AI-让它照着做.md`](./2-发给你的AI-让它照着做.md) 丢给你的 AI，它会接好浏览器调试会话并自动出报告。
